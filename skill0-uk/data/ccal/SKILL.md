# ccal — skill0

调休 — правило, за яким вихідний може бути «позичений», щоб із робочого дня вийшов вихідний, або коли свято випадає на вихідний, до робочого дня додається компенсація — це ключова особливість для китайських користувачів, які планують життя за офіційним робочим календарем.

## Швидкий старт з `x ccal`

```bash
# Показати всю інформацію про дати у формі tsv. Стовпці TSV такі:
# Date   LunarDate   建除(зведені підтипи дня)   WeekDay(день тижня)   Jieqi(сонячний термін)   Xiuxi(три стани:休 — вихідний, 工 — робочий, 无 — звичайні, не зумовлені перенесенням)   Yi（宜）— доречно   Ji（忌）— не варто   Holiday
x ccal ls 2026
# Показати всю інформацію про дати у формі tsv
x ccal ls 2026-07
# Конкретна дата у YAML
x ccal info 2026-05-31
# Отримати каталог даних. Якщо він порожній, спробуйте `x ccal update`
x ccal datadir
```

`x ccal -h` — докладніше.

Зверніть увагу: джерело даних — https://codeberg.org/x-cmd/ccal-data/releases/download/latest/ccal-data.tar.xz

Щоб заощадити місце, `x ccal` гортає tar.xx через команду tar, не розпаковуючи архів. Ми заохочуємо цей підхід, але якщо потрібна більша свобода обробки, розпакуйте за потреби.
