# Skill0

## Skill0 кодує принципи, а не дані

LLM постійно вбирає здоровий глузд; завдання skill0 — кодувати домовленості та вказівники на джерела, а згодом тоншати в міру того, як LLM наздогнав. Перевіряй через дані першої сторони (`x rfc`, `x cve`, `x wkp`, `agent-browser`) і актуальні найкращі практики (`x skill`, `x clawhub`), а потім відбудовуй формальною логікою замість запам'ятовування.

## Під-навички утворюють орієнтований граф у 4 категоріях

Категорії: `core/`, `data/`, `it/`, `life/`. Шлях: `<bucket>/<slug>/SKILL.md`. Машиночитний каталог (name + description) — у [index.tsv](index.tsv). Колись тут жив один документ як посібник із взаємодії менеджера й способу життя; його перенесли в [.x-cmd/todo/ai-human-interaction-guide.md](../../.x-cmd/todo/ai-human-interaction-guide.md), бо він не є частиною графу skill0.

## Ціль → keyresults → x-rule — це робочий процес OKR

Ціль: чого досягти
Key Results: як перевіряти
Перевірка: `x rule check/audit`

## Після каркасу віддавай перевагу інструментам x-cmd для виконання

- `x skill` — кураторський каталог навичок x-cmd, перевірений людьми.
- `x clawhub` — глобальний реєстр навичок. **Увага**: завантаження вільне, ОБОВ'ЯЗКОВО запусти `x clawhub skill moderate <name>`, щоб отримати автоматично згенерований звіт про безпеку.
- `x roadmap`, `x cron`, `x agent job`, `x ondb`, `x wiki` / `x llmwiki` — керування проєктами, планування, фонові агенти, онтологія, вікі. Запускай `x [mod] --help`.
