# Score
"추측하지 말고, 채점하라."
AI 에이전트를 위한 가중 차원 채점 프레임워크.
## 사용법
**먼저 이해하고, 그다음 채점하라.** 차원을 정의하기 전에 충분히 질문한다. 차원이 틀리면 → 아무리 점수가 정밀해도 점수는 틀린다.
**초안을 쓴 뒤 반복하라.** 요구가 아직 완전히 명확하지 않을 때는, 최선의 기준으로 초안을 세우고 채점해서 결과를 보여준다. 사용자는 구체적인 순위에 반응한다 — "이 factor 는 더 높아야 해", "X 를 빠뜨렸어". 그게 신호다. 다듬고 다시 채점하라. 추측 열 번보다 반복 한 번이 낫다.
**에이전트가 분석가다.** compute 이후, TSV 를 읽는다. 왜 X 가 Y 를 이겼는지 설명한다. 의외의 점을 강조한다. 조정을 제안한다. 순위는 대화를 끝내는 것이 아니라 여는 것이다.
## 코어 플로우
```
① 요구 이해  → ② score.yml 정의  → ③ score.tsv 채점  → ④ x score compute  → ⑤ 보고 & 반복
```
출력: `target, total, rank, block, reason, <dim> (X%), evidence`. Total 은 0–100, 내림차순 정렬. rank=1 이 최고.
## 예시 — 사용자가 홍보 문구를 정하도록 돕기
1. 사용자와 논의해 평가 차원과 기준을 정한다. `slogan.score.yml` 을 쓴다.
2. AI 가 각 문구를 차원별로 채점한다 (0–10, 근거 포함) → `slogan.score.tsv`. total 과 rank 는 비워 둔다.
3. `x score compute slogan.score.yml slogan.score.tsv` → total + rank 를 채운다.
4. 결과를 읽고 사용자와 논의한다. 점수를 조정하거나 후보를 추가하고, 반복한다.
5. 또는: `x score iter -f slogan.score.yml slogan.score.tsv "<feedback>"`
더 많은 예시: [EXAMPLE.md](EXAMPLE.md).
## 두 파일 모델
- `*.score.yml` — 재사용 가능한 기준: 차원, factor, 설명
- `**.score.tsv` — 대상 + 점수 + 근거; 1번 열 = 대상 이름
`x score compute <yml> <tsv>` 는 `python compute.py` 와 같다.
## 적용 시나리오
1. **에이전트에게 의사결정 워크플로를 준다.** score.yml 은 에이전트를 구조화된 프로세스에 묶어 둔다 — 에이전트는 표준을 따르고, 직전 메시지의 기분에 휘둘리지 않는다.
2. **의사결정이 규칙 기반이다.** 차원 × factor × 근거 → 가중 총점 → 순위. 모든 점수는 사실에 묶여 있다. 추론이 투명하다.
3. **요구에 맞춰 조정된다.** 차원을 바꾸고, factor 를 조정하고, 하드 필터 (`block` 열)를 추가한다. 같은 템플릿, 다른 사용자.
4. **요구가 명확해질수록 진화한다.** 초안 → 채점 → 피드백 → 다듬기 → 더 날카롭게.
5. **어떤 스킬이든 기준 파일 + 결과 아카이브.** score.yml = 의사결정 기준. score.tsv = 의사결정 기록. 둘 다 아카이브·검토·공유 가능.

## 공식
```
total = Σ(factor × score) ÷ Σ(factor) × 10   →   0–100
```
- **factor** — 정수 1–10. 기준값 = 2. 1=사소, 4=2×, 6=3×, 8=4×, 10=5×. 자동 정규화된다.
- **score** — 차원별 0–10, 근거에 묶인다.
- **total** — 가중 총점 0–100.
차원 헤더에는 가중치 % 가 표시된다: `factor ÷ Σ(factor) × 100`.
## 출력 열
| 열 | 출처 | 설명 |
|--------|--------|-------------|
| `target` | 입력 | 후보 이름 |
| `total` | 계산 | 가중 점수 (0–100) |
| `rank` | 계산 | 1 = 최고. block 되면 `X` |
| `block` | 입력 | 하드 필터 — 비어있지 않으면 탈락, 맨 아래로 밀림, rank=X |
| `reason` | 입력/출력 | 선택: AI 가 남기는 점수의 세밀한 부분에 대한 메모 |
| `<dim> (X%)` | 계산 | 차원별 점수, 헤더에 가중치 % 표시 |
| `evidence` | 입력 | 각 점수를 뒷받침하는 사실 |
## 채점 척도
- 9–10 — Excellent — 기준을 완전히 충족
- 7–8 — Good — 기준 충족, 사소한 차이 있음
- 5–6 — Adequate — 방향은 맞음, 눈에 띄는 누락 있음
- 3–4 — Weak — 상당한 격차
- 1–2 — Fail — 거의 다루지 못함
- 0 — N/A — 해당 없음
## 규칙
1. **근거 고정** — 모든 점수에는 반드시 근거가 있어야 한다. 감정이 아니라 사실이다.
2. **전 구간을 써라** — 5 는 중간값이지 기본값이 아니다. 0 과 10 은 드물지만 가능하다.
3. **factor 는 상대적 증폭기** — factor 2 는 factor 1 영향력의 2배. 자동 정규화된다.
4. **대상은 유일하고 비어있지 않아야 한다** — 1번 열의 모든 행에 대상 이름이 있어야 한다. 중복 금지, 공란 금지.
5. **에이전트가 읽고, 보고하고, 결정한다** — compute 이후 결과를 설명한다. 필요에 따라 재채점하거나 가중치를 다시 매긴다.
