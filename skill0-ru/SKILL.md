# Skill0

## Skill0 кодирует принципы, а не данные

LLM постоянно впитывает здравый смысл; работа skill0 — кодировать соглашения и указатели на источники, а затем, по мере того как LLM догоняет, постепенно худеть. Проверяй через первичные данные (`x rfc`, `x cve`, `x wkp`, `agent-browser`) и текущие лучшие практики (`x skill`, `x clawhub`), а затем восстанавливай формальной логикой, а не заучиванием.

## Поднавыки образуют ориентированный граф в 4 корзинах

Корзины: `core/`, `data/`, `it/`, `life/`. Путь: `<bucket>/<slug>/SKILL.md`. Машиночитаемый каталог (имя + описание) лежит в [index.tsv](index.tsv). Раньше здесь жил один документ как руководство по взаимодействию manager/lifestyle; его перенесли в [.x-cmd/todo/ai-human-interaction-guide.md](../../.x-cmd/todo/ai-human-interaction-guide.md), поскольку он не часть графа skill0.

## Цель → keyresults → x-rule — это рабочий процесс OKR

Цель: чего достичь
Key Results: как это проверить
Проверка: `x rule check/audit`

## После того как каркас готов, для выполнения предпочитай инструменты x-cmd

- `x skill` — выверенный x-cmd каталог навыков, проверенный человеком.
- `x clawhub` — глобальный реестр навыков. **Внимание**: загрузка свободная, **обязательно** запусти `x clawhub skill moderate <name>`, чтобы получить автоматически сгенерированный отчёт по безопасности.
- `x roadmap`, `x cron`, `x agent job`, `x ondb`, `x wiki` / `x llmwiki` — управление проектами, планирование, фоновые агенты, онтология, вики. Запусти `x [mod] --help`.
